# Kognivon Public Experience Consolidation Baseline — 2026-09-28

## Scope frozen
The current blue-first Kognivon public visual direction is retained. This program is a consolidation and quality upgrade, not a redesign.

## Protected strengths
- Official Kognivon identity and blue/navy palette
- Landing-page information architecture and dark/light section rhythm
- Existing enterprise positioning and workforce-capability narrative
- CRM-backed public pricing architecture
- Contact Sales enterprise inquiry experience
- Shared public header/footer shell

## Baseline issues being corrected
- Too many local border-radius values
- Too many shadow/elevation formulas
- Inconsistent micro-typography between card families
- Local button implementations that approximate the shared button system
- Multiple card interaction grammars
- Horizontal-scroll mobile public navigation
- Pricing merchandising decisions partly inferred in frontend code
- Minor spacing/alignment drift between public routes

## Sanctioned public design contract
Radii: control 12px; card 16px; panel 24px; pill 999px.
Elevation: three levels only — base card, interactive/featured, major floating panel.
Type roles: eyebrow, metadata, small body, body, card title.
Motion: 160ms controls; 220ms cards/panels.
Focus: one high-contrast Kognivon blue focus treatment.
Public content width, section rhythm and blue/navy brand direction remain unchanged.

## Implementation sequence
1. Token layer
2. Header/navigation
3. Button consolidation
4. Card taxonomy
5. CRM merchandising controls
6. Cross-page alignment/content density
7. Interaction/accessibility
8. Responsive certification
9. Performance/code hygiene
10. Visual regression and release gate
